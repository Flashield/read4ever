# Read4Ever 托盘暂停与单实例多开方案

> 日期：2026-10-30　|　状态：已评审
> 决策：托盘暂停用「Rust 收口点 emit 事件 + 前端统一暂停」；单实例用 `tauri-plugin-single-instance` 条件注册，设置存于既有 store，重启生效。

## 1. 需求与范围

- **进入托盘即全停**：关闭按钮隐藏到托盘、菜单栏「隐藏到托盘」、快捷键 T 三条路径，任何一条进入托盘时，所有 tab 的滚屏（含页模式定时翻页）与播放（插件视图实例，含激活 tab）全部暂停。
- **恢复不续播**：从托盘恢复显示后保持暂停，由用户手动继续（已确认，避免长时间隐藏后回来内容已翻过页/播过头）。
- **默认单实例**：默认同时只允许运行一个程序，重复启动唤起已有窗口；设置中心提供「允许同时运行多个程序」，勾选后可多开。
- 非目标：不改变关闭按钮「隐藏到托盘而非退出」的既有语义；不做分实例独立数据（多实例共享同一 `read4ever.json`）；不处理托盘菜单新增项。

## 2. 选型记录

**托盘暂停的事件通道**：

| 方案 | 结论 |
|---|---|
| Rust 收口点 emit（选定） | 三条进入托盘的路径全部收敛在 `commands::hide_main_to_tray` 一个函数，emit 一次全覆盖，前端单一处理器 |
| 前端各自处理 | 前端调 `api.hideToTray()` 前暂停 + 关闭按钮路径 Rust 另发事件：两条代码路径、逻辑重复，排除 |
| 监听 `visibilitychange`/blur | 各平台 webview 隐藏时未必触发 `visibilitychange`；blur 在窗口仅失焦未隐藏时也触发（误暂停），排除 |

**单实例**：

| 方案 | 结论 |
|---|---|
| `tauri-plugin-single-instance` 条件注册（选定） | 标准方案，平台原生互斥（Windows 命名互斥量 / Unix socket 等）；按设置决定是否注册即可支持多开 |
| 自写平台互斥锁 | 重复造轮子，平台代码多且无收益，排除 |
| 总是注册、回调里放行多开 | 不可行：插件机制决定第二个进程必然被终止，回调运行于第一实例，无法放行 |

## 3. 架构

```
关闭按钮 ──▶ on_window_event CloseRequested ─┐
菜单「隐藏到托盘」/快捷键 T ──▶ hide_to_tray ─┤
                                              ▼
                            commands::hide_main_to_tray（唯一收口）
                              ① app.emit("rb-tray-hidden")   ──▶ 前端 pauseAllActivity()
                              ② 隐藏窗口                          ├─ reader.stopScroll()：停滚屏/页模式翻页、
语义：暂停不销毁；恢复显示后保持暂停，                          │   释放 "reading" 屏幕常亮
由用户手动继续                                                  └─ plugins.pauseAllInstances()：全部
                                                                  实例 isPlaying→togglePlay（媒体坞
                                                                  迷你条随 play/pause 回调自动刷新）

启动时：read4ever.json 的 allowMultipleInstances ──▶ false: 注册 single-instance 插件（重复启动回调
        （缺失/损坏一律 false）                        唤起+聚焦已有窗口）／ true: 不注册，正常多开
```

暂停走实例既有 `togglePlay` 接口（与切 tab 播放策略 `tabs.applyPlaybackPolicy` 同一通道），不引入新的实例控制面；范围从「后台 tab」扩大到「全部实例（含激活）」。

## 4. Rust 侧

### 4.1 托盘暂停事件

`commands.rs::hide_main_to_tray`：隐藏窗口**前** `let _ = app.emit("rb-tray-hidden", ());`（`use tauri::Emitter;`）。emit 失败不影响隐藏。`show_main_from_tray` 不动（保持暂停语义）。托盘「退出」走 `app.exit(0)`，无需暂停。

### 4.2 单实例条件注册

`Cargo.toml`：

```toml
# 默认单实例：重复启动唤起已有窗口（docs/spec/托盘暂停与单实例多开方案.md）
[target.'cfg(any(target_os = "linux", target_os = "macos", target_os = "windows"))'.dependencies]
tauri-plugin-single-instance = "2"
```

`lib.rs::run()` 重构：先 `let ctx = tauri::generate_context!();`，读设置后按需注册，最后 `builder.run(ctx)`：

```rust
let ctx = tauri::generate_context!();
let allow_multiple = store::read_allow_multiple(&ctx.config().identifier);
let mut builder = tauri::Builder::default();
if !allow_multiple {
    // single-instance 插件要求最先注册
    builder = builder.plugin(tauri_plugin_single_instance::init(|app, _argv, _cwd| {
        commands::show_main_from_tray(app); // 重复启动 → 唤起+聚焦已有窗口
    }));
}
let builder = builder
    .plugin(tauri_plugin_opener::init())
    // …既有插件与 setup 不变
```

依赖与注册代码按目标门控（先例同 keepawake/trash）：插件无 iOS 后端，仅桌面三平台引入。

## 5. 前端侧

| 位置 | 变更 |
|---|---|
| `app.ts` | 新增 `pauseAllActivity()`：`reader.stopScroll()` + `plugins.pauseAllInstances()`。`boot()` 中注册两个监听：`window.addEventListener("rb-tray-hidden", pauseAllActivity)`（mock 路径）+ Tauri 环境下动态 `import("@tauri-apps/api/event")` 的 `listen("rb-tray-hidden", pauseAllActivity)` |
| `registry.ts` | 新增 `pauseAllInstances()`：遍历 `views` Map，try/catch 内 `isPlaying?.()` 为真则 `togglePlay?.()`（模式同 `tabs.applyPlaybackPolicy`，范围含激活实例） |
| `mock_backend.ts` | `hide_to_tray` 分支派发 `window.dispatchEvent(new CustomEvent("rb-tray-hidden"))`，浏览器预览行为一致 |
| `types.ts` | `Settings` 加 `allowMultipleInstances: boolean; // 允许多实例（重启后生效）` |
| `app.ts` 默认值 | `allowMultipleInstances: false` |
| `index.html` 设置中心 | 「允许同时运行多个程序（重启后生效）」复选框，置于标签页设置附近 |
| `settings.ts` | 照 `set-tab-switch-continue` 模式 `set`/`bindCheck` |

已知可接受行为：插件 `togglePlay` 路径的个别 toast（如「已停止播放」）在隐藏期间不可见且自动消失；隐藏后立即唤回可能瞥见，属提示性信息，不处理。

## 6. 错误处理

| 情形 | 行为 |
|---|---|
| store 文件缺失/损坏/字段类型不符 | `read_allow_multiple` → false（单实例兜底，保守方向） |
| 多开设置运行中修改 | 不即时生效；重启后生效（UI 文案注明），互斥机制在启动瞬间定型 |
| emit 失败 | `let _` 忽略，窗口照常隐藏；下次进入托盘再试 |
| 实例 `isPlaying`/`togglePlay` 抛异常 | try/catch 跳过该实例，继续处理其余（与切 tab 策略同） |
| 多实例共享 store | 最后写入者胜：设置/书签以最后保存实例为准，设计内接受 |
| 多开时托盘图标 | 每实例各一个，设计内接受 |

## 7. 验证

无前端测试 runner，遵循现状：Rust 单测 + 手动验证。

1. `cargo test`：新增 `parse_allow_multiple` 用例（true / false / 字段缺失 / 类型不符 / 坏 JSON / 空串）+ 既有回归。
2. `npm run build`：tsc 类型检查通过。
3. 三条路径分别验证：滚屏中进托盘 → 恢复后滚屏已停、`systemd-inhibit --list` 常亮抑制消失。
4. 多 tab 播放：tab A 视频播放 + tab B 图片幻灯 + 激活 tab 滚屏 → 进托盘 → 恢复后全部暂停、媒体坞迷你条消失。
5. 单实例：默认设置下二次启动 → 不出新进程，原窗口唤起并聚焦（含托盘隐藏态）。
6. 多开：设置勾选 → 重启 → 可启动第二实例（各自托盘图标）；改回 → 重启 → 恢复单实例。
7. 浏览器 mock 模式（`npm run dev`）：触发隐藏 → 暂停逻辑执行无报错。
8. 回归：切 tab 播放策略、托盘显示/退出、正常滚屏/播放不受影响。
