# Read4Ever 托盘视频续播与音频界面主题化方案

> 日期：2026-10-30　|　状态：已评审
> 决策：视频插件新增「最小化托盘仍播放」设置（默认关），经插件接口新可选成员 `trayPlaybackExempt` 动态豁免进托盘全停；音频播放界面曲目列表区文字与悬停底色改为从阅读主题派生（只改颜色，不动字体字号）。Rust 零改动。
> 修订：2026-10-30 实现期弱化色混合比 55% → 65%（质量审查：纯黑夜读主题下序号/空态对比度 2.4:1 → 2.9:1，浅色主题同步更稳）。

## 1. 需求与范围

- **视频「最小化托盘仍播放」**：视频插件固定设置菜单（菜单栏「插件 → 视频查看」）新增勾选项，默认关。开启后，最小化到托盘（关闭按钮 / 菜单「隐藏到托盘」/ 快捷键 T 三条路径）视频继续播放，恢复窗口不暂停；关闭则维持现状（进托盘即暂停，恢复后保持暂停）。
- **仅影响托盘**：切标签页仍暂停视频、关闭视频视图照旧停止、文本滚屏进托盘照常停、音频插件行为完全不动。
- **音频界面主题化**：音频播放界面的曲目列表区透出阅读区主题背景，但文字用固定深色 UI 配色（`--ui-text: #e0e0e0` + `#999`），浅色主题（白纸/护眼绿/米黄等）下无法辨认。改为文字/悬停/弱化色从主题派生。**只改颜色，不改字体与字号**（用户确认）。顶栏/列表栏为固定深色底、文字本就清晰，不动。
- 非目标：不改 Rust 与 mock 后端；不改媒体坞迷你条（深色底）；不给音频/图片/视频查看器换字体字号；不做托盘内的播放控制界面。

## 2. 选型记录

**托盘续播豁免通道**：

| 方案 | 结论 |
|---|---|
| 插件接口新增可选 `trayPlaybackExempt?(): boolean`（选定） | 每次进托盘现读设置动态判断；与音频静态 `backgroundPlayback` 叠加（后者还管切标签页策略 `tabs.applyPlaybackPolicy`，不可复用）；无硬编码，外部插件亦可用 |
| `backgroundPlayback` 改为动态函数 | 波及切标签页策略与音频既有语义，改动面大，排除 |
| registry 按插件 id 硬编码视频特判 | 脏耦合，排除 |

**音频列表主题色派生**：

| 方案 | 结论 |
|---|---|
| `color-mix(in srgb, var(--reader-text) …, transparent / var(--reader-bg))`（选定） | 任意主题（含自定义主题）自动派生对比色；Tauri 三端 WebView（WebView2 / WKWebView / WebKitGTK）2023 起均支持；老内核退化为无底色/原色，不挡使用 |
| 固定 rgba 黑/白叠加 | 自定义主题背景色任意，固定色无法保证对比度，排除 |
| 列表区改固定深色底不再透主题 | 与「背景跟随外观方案」的现状预期相悖（用户要求文字按主题调整而非背景改深），排除 |

## 3. 架构

托盘事件链不变（`hide_main_to_tray` 唯一收口 emit `rb-tray-hidden` → 前端 `pauseAllActivity()`），只在 `pauseAllInstances` 内多一个豁免检查：

```
进入托盘（三路径）→ hide_main_to_tray → emit "rb-tray-hidden" → app.pauseAllActivity()
  ├─ reader.stopScroll()                     （不变）
  └─ plugins.pauseAllInstances()
       ├─ backgroundPlayback → 豁免          （音频，不变）
       ├─ trayPlaybackExempt?.() → 豁免      （新增：视频现读「最小化托盘仍播放」设置）
       └─ 其余实例 isPlaying → togglePlay    （不变）
```

设置存于既有 `settings.pluginSettings["video-viewer"].trayKeepPlaying`（`setPluginSetting` 通用通道，无新 `Settings` 字段，无 Rust 改动；`pluginSettings` 为通用 Record，旧配置缺失即默认值）。

语义说明：勾选后对视频豁免《托盘暂停与单实例多开方案》的「恢复不续播」语义——默认仍保持该方案行为，仅显式勾选的视频例外；隐藏窗口期间媒体元素持续解码出声，恢复后画面接续。

## 4. 前端侧

| 位置 | 变更 |
|---|---|
| `plugins/types.ts` | `Read4EverPlugin` 加可选 `trayPlaybackExempt?(): boolean`：进托盘全停的动态豁免，与静态 `backgroundPlayback` 叠加 |
| `plugins/registry.ts` | `pauseAllInstances()` try 块内、`isPlaying` 判断前加 `if (e.plugin.trayPlaybackExempt?.()) continue;` |
| `video-viewer.ts` | 模块级 `let trayKeepPlaying = pluginSetting<boolean>(PID, "trayKeepPlaying", false)`；插件定义挂 `trayPlaybackExempt: () => trayKeepPlaying`；`menu()` 加勾选项「最小化托盘仍播放」（action 切换 + `setPluginSetting` + toast「最小化到托盘时视频将继续播放 / 将暂停」）；版本 1.3.0 → 1.4.0；description 补充说明 |
| `styles.css` 音频段 | `.av-row` color → `var(--reader-text)`；`.av-row:hover` / `.av-row.cur` background → `color-mix(in srgb, var(--reader-text) 12% / 20%, transparent)`；`.av-idx` / `.av-empty` color `#999` → `color-mix(in srgb, var(--reader-text) 65%, var(--reader-bg))`。其余（`.av-bar` / `.av-listbar` / `.av-error` / `.av-state` / 媒体坞）不动 |
| `README.md` | 功能表补两处：视频插件「最小化托盘仍播放」；音频界面配色跟随阅读主题 |

## 5. 错误处理

| 情形 | 行为 |
|---|---|
| 旧配置无 `trayKeepPlaying` | 默认 false（维持现状：进托盘暂停） |
| 豁免检查抛异常 | 跳过该实例暂停（按豁免方向容错），不阻断其余实例（与既有「单个实例异常不阻断」同一容错精神） |
| 勾选状态切换 | 即存即生效（每次进托盘现读，无缓存一致性问题）；托盘隐藏期间无法操作菜单，天然只在可见态切换 |
| WebView 不支持 color-mix | 悬停/当前行无底色、弱化色保持原色，列表功能不受影响 |
| 隐藏窗口播放的平台差异 | 个别平台 webview 隐藏时视频渲染暂停但音频继续；恢复后画面接续，验证时确认 |

## 6. 验证

无前端测试 runner，遵循现状：手动验证为主。

1. `npm run build`：tsc 类型检查通过。
2. `npm run tauri dev` 打开视频 → 勾选「最小化托盘仍播放」→ 关闭按钮进托盘 → 声音持续、托盘恢复后视频仍在播、进度推进。
3. 取消勾选 → 进托盘 → 恢复后视频已暂停（现状行为回归）。
4. 切标签页：视频播放中切到文本 tab → 视频暂停（新设置不影响切标签页策略）。
5. 文本滚屏中进托盘 → 恢复后滚屏已停（滚屏不受豁免影响）。
6. `npm run tauri dev` 打开音频 → 外观面板切 白纸 / 护眼绿 / 米黄 / 纯黑夜读 / 深蓝夜读 → 曲目列表文字全程可读、悬停与当前行底色随主题、顶栏与列表栏不变、字体字号不变。
7. 浏览器 mock（`npm run dev`）：插件菜单出现新勾选项、切换有 toast、重启后记忆（设置持久化通道验证）。
