# PDF 阅读插件方案

> 跟踪票据：[#1](https://github.com/Flashield/read4ever/issues/1)（ready-for-agent）· 术语见根 [GLOSSARY.md](../../GLOSSARY.md) · 渲染引擎决策见 [ADR-0001](../adr/0001-pdf-render-pdfjs-frontend.md)

## 问题陈述

读者手头有 PDF 文档（中文工作文档、论文、扫描书），Read4Ever 无法打开：文件对话框过滤不掉 `.pdf`、文件夹侧栏点击无响应，只能切去别的阅读器，脱离统一的阅读体验（速度键自动滚屏、常亮、进度记忆、多标签页）。

## 方案

新增**外部插件**「PDF 阅读器」（`.rbplugin` 包），以 pdf.js 渲染 PDF 为连续滚屏视图注入插件视图宿主。本地、zip 内、SMB 远程三类来源全支持，大文件走流式 Range 加载；文本可选中复制；注记（印章/批注）静态可见；进度记忆与恢复。**Rust 侧零改动**。

## 用户故事

**打开途径**
1. 作为读者，我想在文件打开对话框中选择 `.pdf` 文件，以便 PDF 与文本/电子书共用一个入口
2. 作为读者，我想在左侧文件夹侧栏里点击 `.pdf` 直接打开，以便像其他格式一样浏览打开
3. 作为读者，我想打开 zip 压缩包内的 `.pdf` 条目（`zip::条目` 复合路径），以便成套打包的 PDF 当一本书管理
4. 作为读者，我想经 SMB 远程面板打开服务器上的 `.pdf`，以便直接阅读 NAS 上的文档不必先下载
5. 作为读者，我想 PDF 视图与文本 tab 共存于多标签页体系，以便切换对照阅读
6. 作为读者，我想再次打开同一 PDF 时恢复到上次的页码与页内位置，以便接着读
7. 作为读者，我想 PDF 视图支持 Esc 关闭与沉浸全屏，以便与其他插件视图一致

**连续滚屏与自动滚屏**
8. 作为读者，我想所有页连续排成一列滚动，以便像读长文一样不被翻页打断
9. 作为读者，我想速度键 1-9 与 +/− 控制自动滚屏（与文本同档），以便操作习惯统一
10. 作为读者，我想自动滚屏时屏幕常亮、光标隐藏、状态栏显示滚屏状态，以便解放双手
11. 作为读者，我想滚到 PDF 末尾自动停止，以便不会空转
12. 作为读者，我想状态栏显示「第 x/y 页」，以便知道阅读位置
13. 作为读者，我想 Space 暂停/继续自动滚屏（归宿主公共入口），以便跨格式一致

**导航与缩放**
14. 作为读者，我想工具栏输入页码跳转任意页，以便快速定位
15. 作为读者，我想 PgUp/PgDn 与 ←/→ 翻页、Home/End 跳首末页，以便键盘导航
16. 作为读者，我想默认按窗口宽度适配页面，以便开箱即读
17. 作为读者，我想 Ctrl+滚轮与工具栏 +/−/适宽/100% 缩放，以便看清细节
18. 作为读者，我想窗口尺寸变化时自动重新适宽，以便布局不破

**文本与内容**
19. 作为读者，我想选中并复制 PDF 里的文字，以便摘录引用
20. 作为读者，我想看到印章、批注等注记（静态展示），以便审批类文档信息完整
21. 作为读者，我想打开加密 PDF 时输入密码，以便阅读受保护文档
22. 作为读者，我想密码输错可重试，以便不必重开文件
23. 作为读者，我想损坏/非 PDF 文件明确报错而不崩溃，以便知道问题所在

**大文件与远程**
24. 作为读者，我想本地/SMB 大 PDF（2GB+）流式按需加载，以便不必整文件进内存
25. 作为读者，我想 zip 内压缩条目超 256MB 时明确报错，以便理解限制而非假死
26. 作为读者，我想 SMB 上 zip 内 PDF 超 1GB 时提示先缓存到本地，以便有出路

**外观与演示**
27. 作为读者，我想 PDF 原始版面原样渲染（不跟随外观主题），以便文档保真
28. 作为演示者，我想浏览器 mock 模式也能打开演示 PDF，以便无 Tauri 环境验证与演示

## 实现决策

- **外部插件管线**（Rust 零改动）：源码入 `plugins-dev/` 新目录（manifest extensions `[".pdf"]`、显示名「PDF 阅读器」、id `pdf`），`npm run build:plugins` 自动纳入构建；`.pdf` 自动获得对话框过滤、文件夹侧栏、zip 条目路由（经 canOpenFile）。依赖（pdfjs-dist）加根 package.json devDependencies，随插件打包
- **渲染引擎 pdf.js**（ADR-0001）：Canvas 渲染；worker 以 blob 方式内联自启动（不依赖宿主 vite 配置）；cmaps 仅内联简繁中文系列（约 +1MB）；standard_fonts 暂跳过、真实样本出现豆腐块再补；插件包预期 2~3MB
- **渲染方式**：注入宿主 DOM（不用 iframe，同 Markdown/EPUB 先例）；原样渲染不跟随主题
- **连续滚屏**：可视页 ±2 缓冲渲染、离屏回收；接入 `ctx.autoscroll`（attach 后速度键/常亮/光标隐藏/状态栏全部白捡）；onEnd 到末尾即停（无跨章语义）
- **来源矩阵**：声明 `wantsStream`——本地/SMB 普通文件走 `read4ever-stream://` Range 流式（2GB+ 可读）；SMB zip 条目与浏览器 mock 恒无流式 URL → 整读回退；zip 压缩条目自限 256MB 明确报错；SMB zip 条目撞宿主 1GB 硬限时报错提示先缓存本地
- **键盘**：插件容器监听 PgUp/PgDn、←/→ 翻页、Home/End 首末页，以 `setActive` 门控；Space/+/-/1-9/Esc/Ctrl 组归宿主（框架既定让与表）
- **缩放**：适宽默认；Ctrl+滚轮步进；工具栏 +/−/适宽/100%；resize 重适宽（宿主无 Ctrl+滚轮绑定，无冲突）
- **进度**：插件自管 `ctx.setSetting`（EPUB 先例）：存 `{页码, 页内滚动比}`，LRU 200 条、2 秒防抖；不进历史面板、无书签（宿主对插件文件本就不写这两样）
- **注记**：静态渲染注记层（印章/批注可见、不可交互）；表单不做交互填写
- **加密**：pdf.js 密码回调接宿主对话框，错误密码可重试
- **状态栏**：`setStatus` 显示「第 x/y 页」
- **实例语义**：单实例（同 EPUB，不用 createView 多实例工厂）

## 测试决策

- **唯一测试缝：插件视图契约缝**——浏览器 playwright + mock 后端，经 openPath 真实打开文件 → 断言插件视图的外部可见状态（页数、canvas 存在、缩放态、状态栏页码、错误 toast、密码弹窗出现）。只测外部行为，不测虚拟化/防抖等内部实现
- 先例：仓库无自动化测试设施，验证 = `npm run build`（tsc 类型缝）+ 浏览器验证（AGENTS.md 既有指引）；**不为单个插件引入单测框架**
- 素材：`examples/ssrn-3332513.pdf`（英文论文 78 页）、`examples/JS19O.7.1 2026Q2工作量【开发】.pdf`（中文 + AcroForm + 印章注记——注记静态渲染的验收样本）、全零损坏文件（错误路径）；用 playwright print-to-PDF 生成中文合成样本与 500+ 页性能样本
- **性能验收线**：500 页 / 50MB 级文档滚动不卡顿、跳页即时渲染目标页

## 不在范围

页模式/双页对开；夜间反色与主题跟随；Ctrl+F 文内查找、关键词检索覆盖 PDF；表单交互填写；宿主级历史/书签集成；打印/导出/另存；任何 Rust/宿主改动；单测框架引入。（iOS 编译门禁不得被破坏是约束不是工作项。）
