# 多标签页、媒体坞与设置中心方案

日期：2026-10-29
状态：设计已逐节确认，待实施

## 背景与目标

三项需求：

1. **多标签页**：手动选择新文件打开时默认新 tab；每个 tab 独立保存状态
2. **全局媒体坞底部栏**：视频插件的进度条等控制移入全局底部栏，全屏播放时可碰边呼出控制进度；同时为后期音频插件「最小化至此、边听边看图片/文本」预留
3. **设置中心**：工具菜单新增「设置」，文件打开等行为类设置集中管理，菜单去重

## 需求决策记录（已确认）

| 决策点 | 结论 |
|---|---|
| tab 隔离范围 | **文本+插件全隔离**：每个 tab 可有独立的图片/视频视图且切走保活；切 tab 时是否继续播放做成设置项 |
| 打开行为 | 手动打开（Ctrl+O/拖拽/文件夹面板/书架/历史/SMB）= 新 tab；同文件已开则跳转已有 tab；Ctrl+PgUp/PgDn 翻页 = 替换当前 tab；zip 多条目选择 = 当前 tab |
| 底部栏形态 | 媒体激活时出现，平时零占位；F11 沉浸全屏时与现有各栏一致碰屏幕下缘呼出 |
| 设置范围 | 行为类设置入设置弹窗并从视图菜单移除；外观/插件设置维持原位 |
| 技术路线 | 方案 B：插件视图多实例化 + 文本快照重建（见下） |

### 技术路线取舍

- **方案 A（快照模拟隔离，单活视图）**：切 tab 即销毁重建，做不到「切 tab 继续播放」，排除
- **方案 B（采用）**：插件改实例化模型，每个 tab 的插件视图独立保活；文本层不复制阅读引擎（reader.ts 渲染层有 WebKit 兼容风险），按快照重渲染
- **方案 C（文本也全实例化）**：滚动引擎/双页状态多份实例，改动面与回归风险远超收益，排除

### 单例改类对插件隔离性的影响（结论：增强）

- 内置插件：模块级单例变量（`ctx`/`video`/`urlCache`）本就是「全局仅一份视图」的根源；类实例的字段（下标、进度、Blob URL 缓存、流式失败记忆、DOM、监听器）彼此封闭，两个视频 tab 互不干扰
- 外部插件：**兼容隔离**——宿主接口新增可选工厂方法，旧单例接口插件由宿主包装为全局单实例（实例随激活 tab 移动，行为与今天一致），旧插件零改动；只有主动实现新接口才获得多实例
- 共享宿主资源的隔离规则：
  - 屏幕常亮持有 → 多实例**引用计数**（扩展注册表现有机制）
  - 插件固定设置（默认倍速等）→ 按插件 id 全局共享（用户偏好本应跨实例），维持现状
  - 键盘等全局事件 → 仅**激活 tab** 的实例响应，后台实例监听器挂起
  - 插件管理面板停用 → 销毁该插件**全部**实例

## §1 多标签页框架

### 数据模型（新模块 `src/tabs.ts`）

```ts
interface Tab {
  id: string;
  title: string;                    // 文件名；插件视图激活时用插件上报的 title
  text: TextSnapshot | null;        // 文本层快照
  view: PluginViewInstance | null;  // 本 tab 的插件视图实例（保活或 null）
}
interface TextSnapshot {
  filePath: string;                 // zip 为复合路径
  zipPath: string; zipEntry: string; isZip: boolean;
  encoding: string;                 // 打开时定死，恢复不重猜
  ratio: number;                    // 滚动位置 0..1
  readSeconds: number;
  raw: string | null;               // 有未另存修改（局部编辑）时驻留内存；否则 null 激活时重读
}
```

分层原则：一个 tab = 文本层 + 可选插件视图层。切 tab 流程：`state`（现有单文件状态，语义不变、始终代表激活 tab）快照回旧 tab（执行与关闭文件相同的进度/时长落账，保证历史准确）→ 从目标 tab 恢复进 `state` → 重渲染 / 显示其插件面板。

### DOM 结构

```
#tab-bar          ← 新增：工具栏与阅读区之间；0 个 tab 时整条隐藏
#reader-container
  #reader-content      ← 单例文本渲染管线，不动
  #plugin-view-host
    .plugin-view-pane  ← 每实例一个面板：激活 tab 的可见，其余 display:none 保活
                           （display:none 下 <video> 继续出声，满足后台播放）
```

### 插件接口扩展（`src/plugins/types.ts`）

```ts
interface PluginViewInstance {
  open(ctx: PluginOpenContext): void | Promise<void>;
  deactivate(): void;
  togglePlay?(): void; navFile?(delta: number): void; isPlaying?(): boolean;
}
interface Read4EverPlugin {
  // …现有字段不变…
  createView?(): PluginViewInstance;   // 新增可选：实现即支持多实例
}
```

- 内置图片/视频查看器重构为 class 实现工厂；单例字段全部迁入实例
- 旧接口外部插件经 `wrapSingleton()` 包装为全局单实例
- `pluginMenuItems`、管理面板、插件设置均按插件 id 工作，不变

### 打开分流（`app.ts`）

| 动作 | 行为 |
|---|---|
| Ctrl+O / 拖拽 / 文件夹面板 / 书架 / 历史 / SMB | 按 `openInNewTab`（默认开）新开 tab；同文件已在某 tab → 跳转 |
| Ctrl+PgUp / Ctrl+PgDn | 替换当前 tab（销毁其插件实例，同 tab 换文件，现状语义） |
| zip 多条目选择弹层 | 当前 tab 打开所选条目 |
| 插件视图 ✕ | 只关视图层，回到该 tab 文本层（现状语义） |
| Ctrl+W | 关闭整个当前 tab（含其插件实例）；最后一个 → 欢迎页 |

### Tab bar UI

- 类型图标（📄/🖼️/🎬）+ 文件名 + 关闭 ×；点击切换；**中键关闭**；溢出横向滚动；激活态高亮
- v1 不做拖拽排序、右键菜单（非目标）

### 快捷键

- 新增：`Ctrl+Tab` / `Ctrl+Shift+Tab` 下一个/上一个 tab
- 变更：`Ctrl+W` 关闭当前 tab；其余不变

### 启动自动恢复

- settings 增加 `tabs: { path, ratio }[]` + `activeTabIndex`
- **惰性重建**：仅激活 tab 立即打开；后台 tab 只记描述，首次点击才真正加载（避免启动全量读文件/起视频）
- `autoRestore` 关闭时不恢复

### 屏幕常亮引用计数

多实例播放期间按实例计数持有/释放；任一实例 deactivate 或暂停时减计，归零释放（现有 releasePluginAwake 机制扩展）。

### 错误处理

- 后台 tab 的文件被删/移走：激活时打开失败 → toast + tab 进入错误态（保留可手动关闭）
- 插件视图打开失败：同上，tab 错误态
- tab 数达 `tabLimit`（默认 20）：toast 拒绝新建
- 关闭 tab 严格走实例 `deactivate()`：Blob URL、监听器、常亮计数全部释放

## §2 媒体坞底部栏（`#media-dock`）

### 定位与形态

```
#reader-container
#media-dock        ← 新增：阅读区与状态栏之间的普通文档流行（不悬浮遮挡文字）
#status-bar
```

- 无媒体时 `display:none`，零占位，现有布局不变
- F11 沉浸全屏：与 `#status-bar` 同一套吸附机制——`translateY(100%)` 藏于屏幕下缘外，`show-bottom` 碰边呼出、移开收回；全屏播视频时碰下缘即可拖进度，不遮挡画面

### 媒体会话模型（新模块 `src/mediaDock.ts`）

插件视图实例不再把播放控件渲染进视图内部，而是注册为媒体会话：

```ts
interface MediaSession {
  id: string;               // = 插件视图实例 id
  title: string;            // 当前媒体名（换文件时经 update 更新）
  element: HTMLElement;     // 会话控件 DOM（实例自建自管）
  isPlaying(): boolean;
}
// dock API：attach(session) / detach(session) / update(session)
```

### 显示规则（v1 仅视频，规则为音频预留）

| 场景 | Dock 显示 |
|---|---|
| 激活 tab 有视频视图 | **完整控制行**：`▶/⏸` ＋ 当前时间 ＋ 进度条 ＋ 总时长（视频实例 `.vv-seekrow` 整体迁入，视图内进度行删除） |
| 激活 tab 无媒体，后台 tab 有媒体**播放中**（`tabSwitchPlayback=继续`） | **迷你条**：类型图标 + 文件名 + `▶/⏸`，点击跳回该 tab |
| 后台媒体已暂停 | 不显示（恢复 = 切回该 tab） |
| 多个后台会话播放中 | 迷你条并排（极端场景，不特殊优化） |

- 完整控制行只放播放/进度/时间；上一/下一个、倍速、音量、静音、全屏、关闭留在插件顶栏（全屏时顶栏碰上缘、媒体坞碰下缘，各管一摊不重复）
- 未来音频插件：音频无舞台画面，天然常驻为迷你条（「最小化至此边听边看」的落点），复用同一 `MediaSession` API；具体交互待音频插件设计时定，API 层已兼容

### 联动关系

- tab 切换：`tabSwitchPlayback=暂停` → 切走即 `pause()`，会话退场；`=继续` → 会话保活转迷你条
- tab/实例关闭 → registry 驱动 `detach`，dock 同步清空（严格对称，杜绝悬空会话）
- 屏幕常亮：后台播放中的会话经引用计数继续持锁
- 播放态变化（播完/连播下一集）由实例经 `update()` 推送，迷你条实时同步

## §3 设置中心

### 入口与形态

- 工具菜单 → 「设置…」（工具菜单末尾新增），快捷键 `Ctrl+,`
- 模态弹窗 `#settings-modal`，复用现有 `modal-content` 样式；设置项单列分组
- 即改即存（改动立即生效并 `persist()`，与全 app 一致），无确定/取消，底部「完成」关闭

### 设置项清单

**文件与标签页**

| 设置项 | 来源 | 默认 |
|---|---|---|
| 手动打开文件默认新标签页 | 新增 `openInNewTab` | 开 |
| 切换标签页时后台媒体继续播放 | 新增 `tabSwitchPlayback` | 关（切走即暂停） |
| 标签页数量上限 | 新增 `tabLimit` | 20 |
| 启动时恢复上次阅读 | 自视图菜单迁入 `autoRestore` | 开 |
| 启动时打开文件夹侧栏 | 自视图菜单迁入 `folderAutoOpen` | 保持现状 |
| 文件名自然排序 | 自视图菜单迁入 `naturalSort` | 开 |
| 文件夹列表含子目录 | 新增入口（与文件夹面板勾选框绑定同一设置值，双向同步） | - |

**播放与屏幕**

| 设置项 | 来源 | 默认 |
|---|---|---|
| 滚屏/播放时保持屏幕常亮 | 自视图菜单迁入 `keepAwake` | 开 |
| 页模式翻页间隔（秒） | 新增 UI（`pageInterval` 此前已持久化但无任何界面可调） | 10 |

**不迁入**（保持原位）：外观方案（外观面板）、插件启停与插件固定设置（插件菜单/管理面板）、简繁显示/双页模式/全屏阅读（视图菜单会话级切换）。

### 视图菜单去重

- 移除：启动时恢复上次阅读、滚屏/播放时保持屏幕常亮、启动时打开文件夹侧栏、文件名自然排序
- 保留：外观方案入口、简繁三态、双页模式、全屏阅读

### 配套更新

- `F1` 快捷键列表补充：`Ctrl+,` 设置、`Ctrl+Tab` / `Ctrl+Shift+Tab` 切换标签页、`Ctrl+W` 语义变更（关闭当前标签页）
- README 功能表与结构说明同步（新模块 `tabs.ts`、`mediaDock.ts`、设置中心）

## 测试要点

- tab：新开/跳转已有/替换/关闭最后一个/中键关闭/上限拒绝；切 tab 文本滚动位置与播放状态（暂停/继续两模式）；后台视频继续播放且切回不重头；惰性恢复（重启后仅激活 tab 立即加载）
- 插件多实例：两个 tab 各开一个视频互不干扰；后台实例不抢键盘；停用插件销毁全部实例；旧接口外部插件单实例移动行为不变
- 媒体坞：无媒体零占位；激活 tab 完整行进度拖动；后台迷你条点击跳回；F11 碰边呼出可拖进度；关闭 tab 后 dock 清空
- 设置中心：各设置即改即存重启生效；视图菜单已移除项不再出现；文件夹面板含子目录与设置中心双向同步
- 回归：单文件打开/关闭、SMB、zip、查找、书签、历史落账（切 tab 落账语义）
