# 暂停时保持无边框 — 方案

日期：2026-11-20

## 背景

现状（`app.ts`）：播放中**手动暂停**（Space/菜单/工具栏等经 `togglePlayback` 的入口）在无边框期间**立即退出**还原（`onPlaybackToggled`）；**真实结束**（视频/音频播完、文本到文末、幻灯放完）不经该入口，由 `startPlaybackWatch` 兜底监视延时确认后退出。

用户需求：暂停时可选择**保持**无边框画面（Esc/F9 仍可手动退出），真实结束仍自动退出还原。

## 设置项

「暂停时保持无边框」（`pauseKeepBorderless`，默认**关**＝现状），位于设置中心「播放/滚屏时自动进入无边框模式」下一行。

## 机制

核心是一个模块级标志 `pauseKept`（app.ts）：

- **置位**：`onPlaybackToggled` 停止分支中，无边框且设置开启 → 不退出、置 `pauseKept`，toast 提示。
- **清除**：① 恢复播放（`onPlaybackToggled` 播放分支）；② 兜底监视观察到播放态为 true（防内部恢复后标志残留，避免后续真实播完被误保）；③ 退出无边框（`toggleBorderless`）；④ 监视的无边框早退分支。
- **监视**：`startPlaybackWatch` 中 `pauseKept && !isPlaying()` 时清计时器、不布防退出确认；其余分支不变。

### 手动暂停路径统一

原实现中媒体坞完整控制行与视图控制条的播放按钮**直调实例 `togglePlay`**，绕过 `onPlaybackToggled`，会被监视误判为真实结束（设置开启时暂停 1 秒后仍被退出）。修正：

- `video-viewer.ts` / `audio-viewer.ts` 的控制条 `case "play"` 与媒体坞 `mdPlay` 点击改走 `ctx.togglePlayback()`。这些控件只在视图为**激活实例**时可点，分发目标就是自身，语义等价且进入联动管线。
- 媒体坞**迷你条**（后台会话）不动：它操作后台实例，不影响激活实例的 `isPlaying`，与联动无关。
- 切标签页策略暂停（`tabs.ts`）、进托盘全暂停（`registry.pauseAllInstances`）视为策略性停止，维持现状（退出无边框）。

### 真实结束不受影响

video/audio `ended`、autoscroll `onEnd`、幻灯/滚屏播完、reader 文末（`onPageEnd`）都不经 `onPlaybackToggled`，无标志，监视照常延时确认退出。

## 已知边界（接受）

- 暂停保持期间关闭标签页/换开别的文件：标志残留、无边框停在无播放画面，Esc/F9 一键可退；不值得引入视图生命周期跟踪。
