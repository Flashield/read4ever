# ReadBook 音频插件与播放列表方案

> 日期：2026-10-30　|　状态：已评审
> 决策：内置插件 `audio-viewer` 逐字复刻 video-viewer 模式（多实例视图 + wantsStream 双通道 + 媒体坞会话）；播放列表 = 目录自动队列 + 可持久化的命名播放列表（手工添加文件/文件夹）；后台播放 = 应用内后台（迷你条）+ 托盘豁免（进托盘音频继续播）；记住每曲播放位置自动续播。

## 1. 需求与范围

- **音频播放**：接管常见音频扩展名，提供播放/暂停、进度跳转、时间显示、音量/静音、倍速、循环模式、上一个/下一首。
- **播放列表**：打开任一音频文件时，同目录/同 zip 内音频自动组成「目录队列」（与视频插件的 siblings 连播一致）；另支持多个命名播放列表——手工添加文件/文件夹（递归收集）、拖拽排序、重命名、删除，持久化保存。
- **后台播放**：切换标签页后音频继续播（媒体坞迷你条可控）；窗口进托盘时音频**不**被「托盘暂停」逻辑暂停（豁免），回前台后播放状态不变。
- **续播**：记住每个音频文件的播放位置，重新打开时自动跳到上次位置（听书/长音频场景）。
- **最小化到坞**：播放器视图可一键切到最近的非音频标签页继续阅读，媒体坞保持控制。
- 非目标（YAGNI）：歌词、封面/ID3 元数据解析、系统媒体键（MPRIS/SMTC/Now Playing）、均衡器、睡眠定时器、曲目时长显示、与视频播放互斥。

## 2. 选型记录

**插件结构**：

| 方案 | 结论 |
|---|---|
| 内置插件逐字复刻 video-viewer（选定） | 多实例、媒体坞会话、流式回退、上一/下一首全是现成模式；`streamUrlFor` 对任意本地/SMB 普通路径可用，播放列表跨目录加载无障碍；改动面最小 |
| 全局单例音频服务 | 偏离「视图拥有媒体」的插件模型，媒体坞会话归属与多实例类型需特判；换来的只是「关掉正在播的标签页还要继续响」这一边缘场景，排除 |
| Rust 侧播放（rodio） | 实现量数倍，丢掉 webview 现成编解码管线，iOS 移植需每平台重写，对「简单播放列表」过度设计，排除 |

**后台播放范围**：仅应用内后台 + 托盘豁免；系统媒体控制（MPRIS/SMTC/Now Playing）平台差异大、实现量明显增加，已确认不做。

**交互形态**：播放器视图 + 最小化到坞（README 媒体坞功能表已预留「最小化到坞」会话 API）；「直接在媒体坞播放不占阅读区」无法承载播放列表管理，「仅播放器视图」缺边听边看，均排除。

**生命周期取舍**：播放绑定视图实例——关闭音频标签页即停止播放；最小化到坞（切走标签页）与切标签页不受影响。语义可预期，与视频一致。

## 3. 架构

```
打开 .mp3 等 ──▶ registry 按扩展名接管 ──▶ AudioView 实例（每 tab 独立）
                                            ├─ <audio> 元素（host 面板内，视图态）
                                            ├─ 媒体坞会话（sessionEl 完整控制行；后台时迷你条）
                                            ├─ 队列 queue：初始 = ctx.siblings（目录队列）
                                            │   可切换为已存播放列表 items
                                            └─ 播放通道：streamUrlFor（任意本地/SMB 普通文件）
                                                  └─ 失败回退字节整读（api 层，与打开文件同通道）
模块级共享（同 video 的 rate 模式）：playlists / positions / rate / volume / loopMode
托盘豁免：pauseAllInstances() 跳过 plugin.trayKeepPlaying === true 的实例
单流策略：audio-viewer 模块级实例表，开始播放时暂停其他播放中的 AudioView
```

新建 `src/plugins/audio-viewer.ts`；小改 `src/plugins/types.ts`（`trayKeepPlaying` 可选标记）、`src/plugins/registry.ts`（托盘豁免一处）、`src/mediaDock.ts`（`MediaSession.miniExtra` 迷你条扩展）；注册进宿主（同 video-viewer 的注册位置）。后端预计零改动。

## 4. 插件形态

- PID `audio-viewer`，接管扩展名：`.mp3 .m4a .aac .flac .ogg .opus .wav`。
- `wantsStream: true`：2GB+ 文件走 `readbook-stream://`（HTTP Range 分块）；压缩 zip 条目等不可流式目标自动回退字节整读——同 video 的 `streamFailed/streamRetried` 自愈模式（会话内回退，元数据加载成功即重置）。
- `createView()` 多实例：每个标签页一个 `AudioView`；用户偏好模块级共享，视图态实例私有。
- 无插件菜单：所有控制在播放器 UI 内。
- 实现宿主公共接口 `togglePlay / isPlaying / navFile` 后，菜单栏「滚屏/播放」按钮、「上一个/下一个文件」按钮、Space 键自动生效（零额外接线）。

## 5. 播放器视图 UI

视图占阅读区，纵向两段布局：

```
┌──────────────────────────────────────────┐
│ ♪ 当前曲目名.mp3            [最小化到坞 ⤵] │
│ ⏮  ▶/⏸  ⏭   ──●──────── 1:23/5:40      │
│ 音量 ──●──   倍速 1x▾   循环:列表🔁      │
├──────────────────────────────────────────┤
│ [目录队列(当前文件夹) ▾]  ＋文件 ＋文件夹  │
│ ┌──────────────────────────────────────┐ │
│ │ 1. 第一章.mp3          ▶(播放中)     │ │
│ │ 2. 第二章.mp3                        │ │
│ │ 3. 第三章.mp3          ⚠(解码失败)   │ │
│ └──────────────────────────────────────┘ │
└──────────────────────────────────────────┘
```

- **曲目列表**：点击播放、失败曲目标 ⚠；不显示时长（避免逐曲预载元数据，SMB 远程开销大）。
- **目录队列只读**：由打开文件所在目录/压缩包派生（宿主自然排序），不可拖拽排序、不可移除曲目；「＋文件」「＋文件夹」在目录队列激活时置灰（tooltip：先选择或新建一个播放列表）。
- **已存播放列表可编辑**：点击播放、拖拽排序、悬停曲目行显示 ✕ 单曲移除。
- **列表选择下拉**：「📁 目录队列(当前文件夹)」+ 已存播放列表。切换只换队列与列表显示，不打断当前播放；点击新列表中的曲目才切换播放。
- **播放列表管理**：新建（自动命名「播放列表 N」，双击名称行内重命名）、删除（目录队列是伪列表，不可删）；＋文件（多选对话框）、＋文件夹（递归收集音频扩展名，自然排序复用 `natural.ts`，加入当前选中的已存播放列表）。
- **循环模式**三态循环按钮：列表循环 ↔ 单曲循环 ↔ 播完停止。
- **最小化到坞**：切到最近激活的非音频标签页；不存在其他标签页时置灰。
- **打开即播**：打开音频文件自动播放（浏览器策略拒绝时停在续播点不播，同视频行为）。
- **状态栏上报**（setStatus）：file=当前曲目名、position=`3/25 首`、encoding=`MP3`（扩展名大写，不解析元数据）、display=播放中/已暂停、title=当前曲目名。
- 媒体坞完整控制行（激活会话）与视图内控制并存，均绑定同一 `<audio>` 元素事件，状态天然同步。

## 6. 播放列表数据模型与持久化

存插件设置 `pluginSettings`（宿主按插件 id 隔离，值为 JSON 字符串，两个键）：

```ts
// 键 "playlists"
{
  lists: [{ id: string, name: string, items: string[] }],  // items = 完整路径
  lastListId?: string   // 上次使用的播放列表（仅记忆，不自动加载覆盖目录队列）
}
// 键 "positions"：path → 秒（续播位置）
{ "/home/u/第一章.mp3": 834, "smb://nas/book/第二章.mp3": 102, "…zip::…/第三章.mp3": 45 }
```

- `items` 路径三种形态一视同仁：本地绝对路径、`smb://` 远程普通文件、zip 复合路径（`zip路径::条目名`）。
- **播放通道不受 `loadBytes` 目录安全边界约束**：该边界防 zip 内条目逃逸，不防用户自己经对话框/浏览加入的文件。流式优先（`streamUrlFor` 对任意本地/SMB 普通文件可用）；压缩 zip 条目、mock 环境等回退 api 层字节读取（与打开文件、收藏书架同通道；SMB 复合路径走 SMB 读命令）。
- **续播规则**：打开文件时若 `positions[path]` 存在且 >3 秒则跳转并 toast「已续播 M:SS」；位置表上限 300 条，超出淘汰最旧（按写入序）。位置跨视图/标签页共享（按 path 索引）。
- **落盘时机**：切曲/暂停/关视图时保存 positions；播放中每 15 秒兜底保存一次。playlists 增删改即保存。

## 7. 后台播放与托盘豁免

- **媒体坞**：激活 tab 完整控制行、后台播放迷你条——现有 API 直接用；音频会话 `kind: "audio"`（迷你条 🎵 图标已有）。
- **迷你条增强**：`MediaSession` 加可选字段 `miniExtra?: HTMLElement`，音频会话提供 ⏮/⏭ 按钮（挂在迷你条 ⏸ 之前）；视频不传该字段，行为不变。后台切曲无需跳回标签页。
- **托盘豁免**：`ReadBookPlugin` 加可选标记 `trayKeepPlaying?: boolean`，音频声明之；`pauseAllInstances()`（registry.ts）跳过带此标记的实例——通用机制，不硬编码插件 id。进入托盘：音频继续播，滚屏/视频照旧全停；回前台：音频播放状态不变，其余保持暂停语义不变。
- **单流策略**：一个音频视图开始播放时，暂停其他播放中的音频视图（audio-viewer 模块级实例表实现，同插件的模块级偏好模式）；音频与视频不互斥，用户自主。
- **屏幕常亮**：播放中 `setKeepAwake(true)`（与视频一致），暂停/关闭释放；视图关闭时宿主自动兜底释放。
- **托盘恢复语义确认**：现有「恢复不续播」只针对被托盘暂停的会话；音频未被暂停，无恢复动作。

## 8. 错误处理

- **解码失败/文件失踪**：`<audio>` error 事件 → toast「无法播放：<名称>」+ 列表项标 ⚠ + 自动跳下一首；**连续 3 首失败则停止**（防坏列表整张跑完的失控循环），手动点击任意曲目重置计数。
- **流式失败**：同 video 模式——该路径加入 `streamFailed` 会话内回退字节整读，每路径自愈重试一次，元数据加载成功即重置。
- **浏览器演示环境（mock）**：播放列表 UI、队列逻辑可用，真实解码不可用（与视频现状一致，不特殊处理）。
- **格式支持说明**：实际可解码格式由各平台 webview 决定（Linux WebKitGTK 依赖 GStreamer 插件）；不支持的格式按「解码失败」路径处理，不做扩展名级预判。

## 9. 验证方式

无前端测试框架，沿用项目惯例：`tsc && vite build` 通过 + 手工测试清单：

1. 各格式解码播放（mp3/m4a/flac/ogg/wav；Linux 缺 GStreamer 插件时走失败跳曲路径）。
2. 目录队列：打开即列同目录音频、连播、上一/下一首、菜单栏滚屏按钮、Space 键。
3. 后台播放：切文本标签页继续播、迷你条 ⏸/⏮/⏭、点击跳回。
4. 托盘：进托盘音频继续播、滚屏/视频暂停；回前台音频状态不变。
5. 续播：中途关闭重开自动跳转 + toast；≤3 秒不续播。
6. 播放列表：新建/重命名/删除、＋文件/＋文件夹（递归+自然排序）、拖拽排序、移除曲目、重启后持久化。
7. 跨路径：本地、SMB 普通文件、本地 zip 存储型条目流式；压缩条目回退整读。
8. 单流策略：两个音频标签页，后者开播前者暂停。
9. mock 演示环境不回归（构建可跑、视图可开）。
