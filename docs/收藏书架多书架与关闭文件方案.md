# 收藏书架增强（多书架 / 标签 / 搜索）与关闭文件 方案

日期：2026-10-27
状态：已确认（设计评审通过，待实现）

## 需求

1. 文本文件打开后可以关闭
2. 收藏书架条目可加标签，可按标签快速筛选
3. 收藏书架可按文件名搜索
4. 支持多个书架：可增加、删除、重命名书架

## 已确认的交互决策

| 决策点 | 结论 |
|---|---|
| Ctrl+W 关闭语义 | **逐层关闭**：插件视图激活时先关插件视图（露出底下文本），再按一次关文本；文本打开时直接关文本 |
| 标签多选命中 | **并集**：命中任一选中标签即显示；**按命中标签数降序**排序，同数保持原顺序 |
| 删除书架 | **条目随之删除**（弹确认框）；仅剩一个书架时禁止删除 |
| 搜索/筛选范围 | 作用于**当前书架**（跨书架聚合为未来增强，不做） |

## 设计

### 1. 关闭文件

`app.ts` 新增 `closeFile()`：

```
if 插件视图激活:
    plugins.deactivateActive()
    if 无文本打开 (state.filePath 为空): reader.showWelcome()
else if 文本打开:
    reader.stopScroll()            # 停滚屏/页模式定时
    saveCurrentProgress()          # 最终位置与时长写入历史
    清空 state 文本字段（filePath/realPath/zipEntry/isZip/fileName/
        raw/encoding/modified/isHardLines/prevPositions/readSeconds）
    reader.showWelcome()
    settings.lastFilePath = ""; settings.lastScroll = 0   # 防启动自动恢复"复活"
    persist(); updateUI()
```

- 菜单：文件菜单「另存为…」后加「关闭文件 Ctrl+W」，无文本且无插件视图时 disabled
- `shortcut.ts` 注册 Ctrl+W
- 局部编辑弹窗开着时不特殊处理（Esc 分级已有；`modified` 仅弹窗期间为真，编辑是即时写回的）

### 2. 多书架

**数据结构**（types.ts / store.rs 同步）：

```ts
interface Bookshelf {
  id: string;          // crypto.randomUUID()；迁移固定 "shelf-default"
  name: string;
  items: BookshelfItem[];
}
// StoreData.bookshelf: BookshelfItem[]  →  StoreData.bookshelves: Bookshelf[]
// Settings 增加 bookshelfActiveId: string  # 当前书架，启动恢复
```

**迁移**（两处，保证旧数据无损）：

- Rust `load_store`：解析后若 `bookshelves` 为空且旧扁平 `bookshelf` 非空 → 收进 `{ id: "shelf-default", name: "默认书架", items: 旧列表 }`；旧字段以 `#[serde(default, skip_serializing_if = "Vec::is_empty")]` 保留反序列化能力、不再写出
- 前端 `mergeDefaults`（浏览器 mock 的 localStorage）：同样迁移；并保证任何情况下至少 1 个书架（全空则建「默认书架」）

**UI**（书架面板 header 与列表之间新增书架行）：

- 横向书架 chips（可换行），点击切换当前书架（写 `settings.bookshelfActiveId` 持久化；id 失效回退第一个）
- 当前 chip 旁 ✎ 重命名（行内变输入框，回车确认，空名忽略）、🗑 删除（确认框「条目将随之删除」；仅剩一个时禁用）
- 行尾「＋ 新建」：行内出现输入框，回车确认（空名忽略）
- 「添加当前」加入**当前书架**（收藏新条目 `tags: []`）

### 3. 标签

**数据**：`BookshelfItem.tags: string[]`；Rust `#[serde(default)] pub tags: Vec<String>` 兼容旧 JSON。

**面板 UI**（书架行之下）：

- 标签 chip 行：**当前书架**出现过的全部标签去重列出，点击切换选中（多选并集），含「全部」chip 一键清除
- 筛选排序：命中任一选中标签即显示，按命中标签数降序，同数保持原顺序；未选标签时维持现有顺序
- 行内：条目描述行显示标签小 chips；行尾 🏷 按钮 → 该行下方**行内展开**编辑区：输入框（逗号/空格/回车分隔添加）+ 建议标签 chips（**词表 = 全部书架所有条目标签并集**，已含的标识可点击移除）+ ✕ 收起；编辑即时生效并持久化
- 输入清洗：trim、去重、忽略空串；超过 20 字符截断

### 4. 文件名搜索

- 书架行下搜索框「搜索文件名…」，实时过滤：不区分大小写，匹配 `name`，兜底匹配 `filePath`
- 与标签筛选叠加（AND）

## 边界与错误处理

- `bookshelfActiveId` 指向已删书架 → 回退第一个书架
- 书架名/标签空串一律忽略；重命名允许同名（id 区分）
- 关闭文件后状态栏/标题/菜单 disabled 状态全部回退到「未打开」（现有 updateUI 已覆盖）
- 旧 `readbook.json` 无 tags / 无 bookshelves 字段 → serde default + load_store 迁移，round-trip 不丢数据
