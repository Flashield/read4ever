# 滚屏/播放公共入口重构实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 菜单栏滚屏按钮重构为「滚屏/播放」公共入口（公用方法），按打开文件类型分发——文本滚屏、图片按所选模式（滚屏/幻灯）播放、视频暂停/继续；上一个/下一个文件同样分发，可跳转上一个/下一个图片或视频。

**Architecture:** 宿主 app.ts 暴露公共入口 `togglePlayback()` / `isPlaying()`；`ReadBookPlugin` 接口新增三个可选方法 `togglePlay?` / `navFile?` / `isPlaying?`（内置插件与外部 .rbplugin 共用同一接口，外部插件实现即可被宿主按钮驱动）；`PluginOpenContext` 新增 `togglePlayback()` 供插件反向调用宿主入口。分发方向：宿主按钮/Space → `app.togglePlayback()` → 插件视图调 `plugin.togglePlay()`，文本视图走原滚屏逻辑。

**Tech Stack:** TypeScript（无前端测试框架，验证门为 `npx tsc --noEmit` + 手工 QA）、既有插件注册表管线。

**验证方式说明:** 本项目无单元测试设施（package.json 无 test runner），按既有惯例以 `npx tsc --noEmit` 作每步类型门禁，最后 `npm run build` + `npm run tauri dev` 手工验证。

function togglePlayback(): void {
  if (slideOn || scrollOn) {

  if (playMode === "slide") setSlideshow(true);

function navFile(delta: number): void {

  else void retreat();
}

## 设计说明（供执行者理解）

- **分发方向**：宿主按钮/Space/菜单 → `app.togglePlayback()`（公用方法）→ 插件视图 `plugin.togglePlay()`；外部 .rbplugin 与内置插件共用 `ReadBookPlugin` 接口，实现可选方法即被宿主按钮驱动，loader 的形状校验只查必填字段，可选方法透传无阻。
- **插件反向调用**：`ctx.togglePlayback()` 供插件触发宿主同一入口（如插件自定义键位路由），闭环于同一分发。
- **图片"所选模式"**：`playMode` 持久化为插件固定设置（settings.pluginSettings["image-viewer"].playMode），用户在图片工具栏点「滚屏」或「幻灯」即记住，宿主按钮按它开始；播放中再按统一停止。
- **视频 Space 单路径**：video-viewer 自身 onKey 的 Space 移除，避免与宿主分发双重触发（切两次等于没切）。
- **范围界定**：视频上一/下一个沿用既有 siblings 语义（同目录/同压缩包内），跨容器接续仅图片查看器已有——不在本次扩展（YAGNI，需要时另行立项）。
