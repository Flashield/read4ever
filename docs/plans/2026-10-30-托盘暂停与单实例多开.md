# 托盘暂停与单实例多开 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 进入托盘（关闭按钮/菜单/快捷键 T 任一路径）时暂停全部标签页的滚屏与播放（恢复后保持暂停）；默认单实例运行（重复启动唤起已有窗口），设置中心可允许多开（重启生效）。

**Architecture:** Rust 唯一收口点 `hide_main_to_tray` 隐藏窗口前 emit `rb-tray-hidden` 事件，前端统一处理器停滚屏引擎 + 遍历插件实例表暂停播放；单实例用 `tauri-plugin-single-instance` 按 store 设置条件注册（Builder 构建期无 AppHandle，按平台复算 store 路径读设置）。

**Tech Stack:** Tauri 2（Rust 后端 + 原生 TS 前端）、tauri-plugin-single-instance 2、serde_json。设计文档：`docs/spec/托盘暂停与单实例多开方案.md`。

```rust
/// 无 AppHandle 时复算 app_data_dir（与 tauri 同源逻辑；单实例启动判定用）：
/// Linux $XDG_DATA_HOME 或 ~/.local/share；macOS ~/Library/Application Support；Windows %LOCALAPPDATA%
fn app_data_dir_no_handle(identifier: &str) -> Option<PathBuf> {
    #[cfg(target_os = "linux")]
    {
        let base = std::env::var_os("XDG_DATA_HOME")
            .filter(|v| !v.is_empty())
            .map(PathBuf::from)
            .or_else(|| {
                std::env::var_os("HOME")
                    .map(|h| PathBuf::from(h).join(".local").join("share"))
            })?;
        Some(base.join(identifier))
    }
    #[cfg(target_os = "macos")]
    {
        let home = std::env::var_os("HOME")?;
        Some(
            PathBuf::from(home)
                .join("Library")
                .join("Application Support")
                .join(identifier),
        )
    }
    #[cfg(target_os = "windows")]
    {
        let base = std::env::var_os("LOCALAPPDATA").filter(|v| !v.is_empty())?;
        Some(PathBuf::from(base).join(identifier))
    }
    #[cfg(not(any(target_os = "linux", target_os = "macos", target_os = "windows")))]
    {
        let _ = identifier;
        None
    }
}

/// 从 store JSON 读 allowMultipleInstances；缺失/损坏/类型不符一律 false（单实例兜底）
fn parse_allow_multiple(json: &str) -> bool {
    serde_json::from_str::<serde_json::Value>(json)
        .ok()
        .and_then(|v| v.get("settings")?.get("allowMultipleInstances")?.as_bool())
        .unwrap_or(false)
}

/// 启动早期（尚无 AppHandle）读多开设置，决定是否注册单实例插件
pub fn read_allow_multiple(identifier: String) -> bool {
    app_data_dir_no_handle(&identifier)
        .and_then(|dir| fs::read_to_string(dir.join("readbook.json")).ok())
        .map(|json| parse_allow_multiple(&json))
        .unwrap_or(false)
}
```

```rust
pub fn run() {
    let ctx = tauri::generate_context!();
    // 默认单实例：store 设置允许多开时不注册插件（变更重启后生效；缺失/损坏一律单实例兜底）
    let allow_multiple = store::read_allow_multiple(ctx.config().identifier.clone());
```

```ts
/** 全部插件视图实例暂停播放（进入托盘时调用；含激活实例，恢复显示后保持暂停）。
 *  通道与切标签页播放策略 tabs.applyPlaybackPolicy 一致，范围扩大到全部实例。 */
export function pauseAllInstances(): void {

  }
```
