# SMB 点击目录自动刷新 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 远程面板点击树中目录（含展开）即失效该目录缓存、从服务器重拉最新条目并渲染，下方文件列表同步拿到新数据。

**Architecture:** 仅改 `readbook/src/smb.ts`。新增 `dropDirCacheOnly`（只删目录自身缓存键，服务器根别名/规范共享根双键同删）；树点击「展开」分支与右键「在下方列出文件」先失效再渲染；`renderTree`/`renderList` 加重入守卫序号，过期请求放弃写 DOM（点击把网络往返带进渲染路径，快速连点必须防串台）。

**Tech Stack:** 原生 TypeScript（无前端框架）、tsc + vite。无前端测试设施，验证 = `npm run build` 过类型检查 + 浏览器 mock 手动验证（mock 后端已实现 SMB 演示服务器）。

**设计文档:** `docs/spec/SMB点击目录自动刷新方案.md`

### Task 1: 渲染重入守卫（行为不变，内部加固）

**Files:**
- Modify: `readbook/src/smb.ts`（模块级变量声明区、`renderTree`、`buildServerNode`、`buildDirNode`、`renderList`）

原理：两个容器各自持有序号（不能用单一全局序号——`renderAll` 里 `renderTree` 与 `renderList` 顺序执行，全局序号会互相踩）。过期判定点放在每个 `await` 之后、任何 DOM append / `nodeRows.set` 之前。`nodeRows` 供 `startMkdir` 定位插入点，过期渲染的节点若登记进去会让新建文件夹输入框插进游离子树（不可见、假死）。

- [ ] **Step 2: renderTree 加守卫**

`renderTree` 全函数替换为（改动：捕获 `my`、循环里 await 后检查、`buildServerNode` 传 `my`）：

```ts
async function renderTree(): Promise<void> {
  const box = $("smb-tree");
  const my = ++treeSeq; // 重入守卫：期间有新渲染启动则放弃本次写 DOM
  const keepScroll = box.scrollTop;
  box.innerHTML = "";
  nodeRows.clear();
  const list = servers();
  if (list.length === 0) {
    box.innerHTML = '<div class="kw-empty">点击上方「＋ 服务器」添加 Samba/NAS 共享</div>';
    return;
  }
  for (const s of list) {
    const node = await buildServerNode(s, my);
    if (my !== treeSeq) return; // 过期：新渲染已接管此容器
    box.appendChild(node);
  }
  box.scrollTop = keepScroll;
}
```

- [ ] **Step 3: buildServerNode 加 my 参数**

`buildServerNode` 全函数替换为（改动：签名加 `my`、`loadChildren` 后检查、子目录递归传 `my`、循环顶部每轮复查——子项 await 期间可能已过期，不得再递归/登记）：

```ts
async function buildServerNode(s: SmbServer, my: number): Promise<HTMLElement> {
  const rootPath = `smb://${s.id}`;
  const node = document.createElement("div");
  node.className = "ft-node";
  node.appendChild(serverRow(s, expanded.has(rootPath)));
  nodeRows.set(rootPath, node);
  if (expanded.has(rootPath)) {
    const kids = document.createElement("div");
    kids.className = "ft-kids";
    const entries = await loadChildren(rootPath);
    if (my !== treeSeq) return node; // 过期：整棵节点由调用方丢弃
    for (const e of entries) {
      if (my !== treeSeq) return node; // 过期：不再递归、不再登记 nodeRows
      if (e.isDir) {
        kids.appendChild(await buildDirNode(e.path, e.name, 1, my));
      } else {
        kids.appendChild(treeFileRow(e, 1));
      }
    }
    if (entries.length === 0) {
      const empty = document.createElement("div");
      empty.className = "ft-emptyline";
      empty.style.paddingLeft = 1 * 14 + 30 + "px";
      empty.textContent = "（空）";
      kids.appendChild(empty);
    }
    node.appendChild(kids);
  }
  return node;
}
```

- [ ] **Step 4: buildDirNode 加 my 参数**

`buildDirNode` 全函数替换为（改动同上，另注意：`nodeRows.set` 在首个 await 之前同步执行，早于过期发生即被新渲染的 `nodeRows.clear()` 清掉，不会残留游离引用）：

```ts
async function buildDirNode(dirPath: string, name: string, depth: number, my: number): Promise<HTMLElement> {
  const node = document.createElement("div");
  node.className = "ft-node";
  node.appendChild(dirRow(dirPath, name, depth, expanded.has(dirPath)));
  nodeRows.set(dirPath, node);
  if (expanded.has(dirPath)) {

    kids.className = "ft-kids";
    const entries = await loadChildren(dirPath);
    if (my !== treeSeq) return node; // 过期：整棵节点由调用方丢弃
    for (const e of entries) {
      if (my !== treeSeq) return node; // 过期：不再递归、不再登记 nodeRows
      if (e.isDir) {
        kids.appendChild(await buildDirNode(e.path, e.name, depth + 1, my));
      } else {
        kids.appendChild(treeFileRow(e, depth + 1));
      }

      empty.className = "ft-emptyline";
      empty.style.paddingLeft = depth * 14 + 30 + "px";
      empty.textContent = "（空）";
      kids.appendChild(empty);
    }
    node.appendChild(kids);
  }
  return node;
}
```

- [ ] **Step 1: 新增 dropDirCacheOnly**

紧随 `dropDirCache` 函数之后新增。判定条件与 `loadChildren` 的双写条件严格对称（alias=`smb://<id>` 两段、canon=`smb://<id>/<share>` 三段且第三段等于 share）：

```ts
/** 仅失效目录自身缓存（点击重拉用）。服务器根别名 smb://<id> 与规范共享根
 *  smb://<id>/<share> 指向同一目录，双键一起删；深层目录只删自己的键——
 *  不复用 dropDirCache（它对任意子目录都连带删共享根双键，点击会误伤、多打网络） */
function dropDirCacheOnly(dir: string): void {
  childrenCache.delete(dir);
  const segs = dir.replace(/\/+$/, "").split("/").filter(Boolean);
  if (segs.length < 2 || segs[0] !== "smb:") return;
  const srv = servers().find((s) => s.id === segs[1]);
  if (!srv) return;
  const canon = `smb://${srv.id}/${srv.share}`;
  const alias = `smb://${srv.id}`;
  if (dir === canon || dir === alias) {
    childrenCache.delete(canon);
    childrenCache.delete(alias);
  }
}
```

- [ ] **Step 2: 树点击「展开」分支接线**

`bindRowEvents` click 处理器中的目录分支（现注释「服务器根/目录：切换展开；目录同时把下方列表切到该目录」）替换为。只在**展开**时失效——收起不产生内容展示，重拉是浪费且下方列表会闪一次网络等待：

```ts
    if (row.dataset.dir === "1") {
      // 服务器根/目录：切换展开；展开即重拉该目录（失效缓存后渲染自然取最新）；
      // 目录同时把下方列表切到该目录
      if (expanded.has(path)) {
        expanded.delete(path);
      } else {
        expanded.add(path);
        dropDirCacheOnly(path);
      }
      if (!row.dataset.server) selectedDir = path;
      void renderAll();
      return;
    }
```
