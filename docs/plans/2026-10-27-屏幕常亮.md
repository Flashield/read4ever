# 屏幕常亮 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 滚屏/页模式定时翻页/插件播放(图片幻灯·自动滚屏·视频)期间保持屏幕常亮,插件经 `ctx.setKeepAwake` 可调用,用户可在视图菜单关闭。

**Architecture:** 前端来源聚合(`src/keepawake.ts` 维护 Set,非空且设置开启才调后端)+ 后端单开关幂等命令(`set_keep_awake`,RAII guard)。桌面三平台用 keepawake crate(target 门控依赖,iOS no-op 占位)。设计全文见 `docs/屏幕常亮方案.md`。

**Tech Stack:** Tauri 2 / Rust(keepawake 0.6)/ vanilla TypeScript。

**测试约定:** 本项目无前端测试 runner、Rust 侧仅个别纯函数有单测(spec §8 已定):每个任务以类型检查(`npx tsc --noEmit`)、`cargo check`、浏览器演示模式(console 可见 `[mock] set_keep_awake`)与桌面手工验证(`systemd-inhibit --list`)代替。提交信息用中文,风格随仓库(如「SMB 远程浏览 步骤2:…」),末尾加 Co-Authored-By 行。

```rust
/* 屏幕常亮：前端按来源聚合成单一开关（docs/屏幕常亮方案.md），此处只持有/释放 RAII guard。
   桌面三平台用 keepawake crate（Linux: org.freedesktop.ScreenSaver + logind Inhibit(fd 锁)；
   macOS: IOPMAssertionCreateWithName；Windows: SetThreadExecutionState），Drop 即释放，
   进程退出/崩溃也随 fd 丢弃自动解除，无需清理代码。
   其余目标（iOS）暂为 no-op：落地时加 objc2-ui-kit 分支，经 app_handle.run_on_main_thread
   设 UIApplication.idleTimerDisabled——命令签名与前端零改动。 */
#[cfg(any(target_os = "linux", target_os = "macos", target_os = "windows"))]
use std::sync::Mutex;

/// cfg 必须与 Cargo.toml 的依赖门控严格一致（不用 cfg(desktop)，防其他桌面目标误入）
#[derive(Default)]
pub struct WakeState {
    #[cfg(any(target_os = "linux", target_os = "macos", target_os = "windows"))]
    guard: Mutex<Option<keepawake::KeepAwake>>,
}

/// 屏幕常亮总开关（幂等）。抑制失败（如无 D-Bus 的环境）只打日志不报错——
/// 屏保抑制是尽力而为的体验增强，不能阻断阅读。
#[tauri::command]
pub fn set_keep_awake(on: bool, state: tauri::State<WakeState>) {
    #[cfg(any(target_os = "linux", target_os = "macos", target_os = "windows"))]
    {
        let mut g = state.guard.lock().unwrap();
        if on {
            if g.is_none() {
                match keepawake::Builder::default()
                    .display(true) // 只阻止屏保/显示休眠，不抑制系统主动睡眠语义
                    .app_name("ReadBook")
                    .reason("滚屏/播放中")
                    .create()
                {
                    Ok(k) => *g = Some(k),
                    Err(e) => eprintln!("[wake] 保持常亮失败（忽略）：{e}"),
                }
            }
        } else {
            *g = None; // Drop 释放
        }
    }
    #[cfg(not(any(target_os = "linux", target_os = "macos", target_os = "windows")))]
    let _ = (on, state);
}
```

- [ ] **Step 1: 新建 `src/keepawake.ts`**

```ts
/* 屏幕常亮来源聚合（docs/屏幕常亮方案.md）。
   前端聚合而非 Rust 计数：后端只需一个幂等总开关，浏览器演示天然 no-op。
   规则：来源集合非空 且 用户设置开启 → 后端开；否则关。谁最后结束谁关灯。 */
import { api } from "./api";

const sources = new Set<string>();
let enabled = true; // 用户设置（app 启动与菜单切换时同步）
let backendOn = false; // 后端当前状态，去重用

function sync(): void {
  const want = enabled && sources.size > 0;
  if (want === backendOn) return;
  backendOn = want;
  api.setKeepAwake(want).catch((e) => console.warn("[keepawake]", e));
}

/** 持有/释放一个常亮来源（阅读侧 "reading"；插件侧 "plugin:<id>"）。幂等。 */
export function holdAwake(source: string, on: boolean): void {
  const had = sources.has(source);
  if (on === had) return;
  if (on) sources.add(source);
  else sources.delete(source);
  sync();
}

/** 清掉某插件的常亮来源（视图关闭时宿主兜底，防外部插件忘关导致永久常亮） */
export function releasePluginAwake(pluginId: string): void {
  if (sources.delete(`plugin:${pluginId}`)) sync();
}

/** 用户设置开关：翻转标志并强制同步（来源集合保留，重新开启后按当前来源恢复） */
export function setKeepAwakeEnabled(v: boolean): void {
  if (enabled === v) return;
  enabled = v;
  sync();
}
```
