# 托盘视频续播与音频界面主题化 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 视频插件新增「最小化托盘仍播放」设置（默认关，仅影响进托盘路径）；音频播放界面曲目列表区文字/悬停/弱化色改为从阅读主题派生（只改颜色，不动字体字号）。

**Tech Stack:** 原生 TypeScript + CSS（无前端框架）。设计文档：`docs/spec/托盘视频续播与音频界面主题化方案.md`。

   *  与静态 backgroundPlayback 叠加、不影响切标签页策略。视频「最小化托盘仍播放」设置用 */

- [ ] **Step 2: registry.ts 的 `pauseAllInstances` 加检查**

现有函数体（注意检查放 try 块内、`isPlaying` 判断之前——豁免检查抛异常时走同一 catch，效果为跳过该实例暂停，不阻断其余）：

```ts
export function pauseAllInstances(): void {
  for (const e of views.values()) {
    if (e.plugin.backgroundPlayback) continue; // 后台播放豁免(音频):托盘不暂停
    try {
      if (e.plugin.trayPlaybackExempt?.()) continue; // 动态豁免(视频「最小化托盘仍播放」):托盘不暂停
      if (e.inst.isPlaying?.()) e.inst.togglePlay?.();
    } catch {
      /* 忽略：单个实例异常不阻断其余 */
    }
  }
}
```

仅新增 try 内第一行，其余不动。
