# ReadBook 插件开发指南

ReadBook 的插件用于接管新文件类型的打开与展示（内置的"图片查看"就是第一个插件）。本文档描述插件架构、包格式与全部可用接口。

## 架构总览

```
┌────────────────────────────────────────────────┐
│ 前端（WebView）                                  │
│  registry.ts 中央打开管线：按扩展名路由到插件      │
│  ├─ 内置插件（随应用编译，如 image-viewer）       │
│  └─ 外部插件（.rbplugin 包，用户自行安装）        │
│      └─ loader.ts：读 main.js → blob import     │
├────────────────────────────────────────────────┤
│ 宿主能力边界（插件唯一入口 = PluginOpenContext）   │
│  文件字节读取（限当前容器）/ 设置读写 / 状态上报    │
├────────────────────────────────────────────────┤
│ Rust 后端（基础能力，不执行插件代码）              │
│  plugin_pkg.rs：安装/卸载/列举/读包内文件         │
│  read_file_bytes / read_zip_entry_bytes / …      │
└────────────────────────────────────────────────┘
```

两条设计原则：

1. **Rust 只提供基础能力**：文件读写、zip 解析、编码处理等随应用编译、经过审计的原语。插件不能携带原生代码（无 dylib、无 WASM 要求），因此不存在"Rust 插件"。
2. **插件仅用 TypeScript 打包**：插件是一个**自包含的单文件 ESM**（`main.js`），不依赖宿主模块、不带 node_modules，所有宿主能力经由 `open(ctx)` 传入的 `PluginOpenContext` 获得。

## 插件包格式（.rbplugin）

`.rbplugin` 就是 zip 压缩包（后缀 `.zip` 也可安装），内含：

```
my-plugin.rbplugin        # = zip
├── manifest.json         # 必需，位于包根
├── main.js               # 默认入口（manifest.entry 可改），自包含 ESM
└── assets/               # 可选资源（图标等，经 ctx 读包内文件能力访问）
```

### manifest.json 字段

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `id` | string | 是 | 全局唯一标识：小写字母/数字开头，仅含小写字母、数字、`-`、`_`，≤64 字符。须与入口导出的 `id` 一致 |
| `name` | string | 是 | 显示名（如「PDF 查看」） |
| `version` | string | 是 | 版本号（如 `1.2.0`） |
| `description` | string | 是 | 一句话描述，显示在插件管理面板 |
| `author` | string | 否 | 作者 |
| `api` | number | 否 | 要求的宿主插件 API 大版本，当前为 `1`（缺省 1；不匹配则拒绝安装） |
| `entry` | string | 否 | 入口文件（包根下的单文件名），缺省 `main.js` |
| `extensions` | string[] | 是 | 可接管的扩展名，小写含点，如 `[".pdf"]`。不能与已启用插件声明的扩展名冲突（冲突时按注册顺序先到先得） |

### 示例

```json
{
  "id": "markdown-viewer",
  "name": "Markdown 查看",
  "version": "0.3.0",
  "description": "渲染 Markdown 文件为富文本阅读视图",
  "author": "you",
  "api": 1,
  "extensions": [".md", ".markdown"]
}
```

## 接口参考

### ReadBookPlugin（入口 default 导出的对象）

```ts
export interface ReadBookPlugin {
  id: string;          // 与 manifest.id 一致（loader 校验）
  name: string;
  version: string;
  description: string;
  extensions: string[];          // 小写含点，如 [".png"]
  wantsStream?: boolean;         // 声明后宿主跳过整文件字节预读，改经 ctx.streamUrlFor 提供流式 URL（大媒体文件）
  open(ctx: PluginOpenContext): void | Promise<void>;  // 渲染视图到 ctx.host
  deactivate?(): void;           // 可选：视图被关闭/切走时的清理（revoke Blob URL、停定时器等）
  menu?(): MenuItemDef[];        // 可选：插件固定设置菜单（显示在菜单栏「插件」菜单）
}
```

`menu()` 返回菜单项数组，每项形如：

```ts
interface MenuItemDef {
  label: string;
  action?: () => void;                 // 点击回调
  checked?: () => boolean;             // 勾选态（如当前生效选项）
  children?: () => MenuItemDef[];      // 子菜单（固定设置分层展开）
  sep?: boolean;                       // 分隔线
  disabled?: boolean;
}
```

### PluginOpenContext（open() 收到的宿主上下文）

| 成员 | 类型 | 说明 |
|------|------|------|
| `path` | string | 完整路径；zip 内条目为 `zip路径::条目名` 复合路径 |
| `name` | string | 文件名 |
| `ext` | string | 小写扩展名（含点） |
| `bytes` | Uint8Array | 文件原始字节 |
| `host` | HTMLElement | 视图宿主容器：把 DOM 渲染进这里，激活期间覆盖阅读区 |
| `siblings` | string[] | 同目录/同压缩包内同扩展名文件（按名称排序），供上一个/下一个 |
| `siblingIndex` | number | 当前文件在 siblings 中的下标 |
| `loadBytes(path)` | Promise\<Uint8Array\> | 读文件字节（自动区分磁盘文件与 zip 条目）。**安全边界：仅允许当前打开文件所在目录/压缩包内的路径**，越界抛错 |
| `streamUrlFor(path)` | string \\| null | 本地文件（含本地 zip **存储型**条目）的流式播放 URL（`readbook-stream://`，宿主按 HTTP Range 分块响应，2GB+ 媒体不整读内存）。SMB/浏览器演示环境返回 `null`，调用方回退 `loadBytes` 整读。需在 ReadBookPlugin 声明 `wantsStream: true` 才存在（宿主会跳过整文件字节预读）；压缩 zip 条目无法区间读取，插件应在 `error` 时回退整读 |
| `listContainer()` | Promise\<string[]> | 列出当前容器全部条目：zip 返回条目名，目录返回文件完整路径 |
| `setStatus(status)` | void | 上报视图状态（见下），增量合并 |
| `getSetting(key, def)` | T | 读插件固定设置（按插件 id 隔离持久化） |
| `setSetting(key, value)` | void | 写插件固定设置（string/number/boolean） |
| `toast(text)` | void | 屏幕下方短暂浮出提示 |
| `setKeepAwake(on)` | void | 持有/释放屏幕常亮（幻灯、自动滚屏、视频播放等场景）。幂等；视图关闭时宿主自动释放，忘关不会永久常亮。同一插件连续打开下一个文件（上一/下一张）时**不自动释放**，插件应在 `open` 中先调 `setKeepAwake(false)` 重置 |

### PluginViewStatus（setStatus 的参数）

插件视图激活期间，主窗口标题、右上角文件名与状态栏各格由插件上报的内容接管；**插件视图关闭时宿主自动恢复文本阅读状态**，插件无需处理退场。

约定与文本阅读一致：**窗口标题/右上角显示"打开的文件"**（zip 内条目显示 zip 自身文件名），**状态栏"文件"格显示"当前查看的文件"**（zip 内当前条目）。

| 字段 | 显示位置 | 示例 |
|------|----------|------|
| `title` | 窗口标题 + 右上角文件名（打开的文件） | `"画册.zip"`（未上报时宿主显示打开的文件名） |
| `file` | 状态栏第 1 格「文件」（当前查看的文件） | `"插图01.png"`（未上报时显示打开的文件名） |
| `encoding` | 状态栏「编码」格（原文显示） | `"PNG 1280×720"` |
| `position` | 状态栏「位置」格 | `"第 2/35 张"` |
| `mode` | 状态栏「模式」格 | `"模式: 适应窗口"` |
| `display` | 状态栏「显示」格 | `"滚屏中·向下"` |

未上报的字段保持上次值；从未上报的字段显示 `-`。

## 生命周期

1. **启用检查**：文件扩展名命中某个**启用中**插件的 `extensions` 时接管打开（txt/zip 恒由宿主处理）。
2. `open(ctx)`：宿主已读好 `bytes`、算好 `siblings`，插件渲染视图到 `ctx.host`。视图就绪前宿主保持旧画面，不会闪现文本。
3. **状态上报**：`open` 内（及此后任何状态变化时）调用 `ctx.setStatus(...)` 更新标题与状态栏。
4. `deactivate()`：视图被关闭（Esc / 打开文本文件 / 插件被停用）时调用，做清理。宿主同时自动释放该插件经 `ctx.setKeepAwake` 持有的屏幕常亮。
5. **Esc 键**：宿主把 Esc 转为关闭插件视图（`deactivate` 会被调用）。

## 完整最小示例

```ts
// src/main.ts —— 插件源码（TypeScript）
import type { PluginOpenContext, ReadBookPlugin } from "./readbook-plugin-types"; // 类型可自备声明文件

const plugin: ReadBookPlugin = {
  id: "hex-viewer",
  name: "十六进制查看",
  version: "1.0.0",
  description: "以十六进制 + ASCII 对照查看文件",
  extensions: [".hex", ".bin"],
  open(ctx: PluginOpenContext) {
    const b = ctx.bytes;
    const lines: string[] = [];
    for (let i = 0; i < Math.min(b.length, 4096); i += 16) {
      const chunk = Array.from(b.slice(i, i + 16));
      const hex = chunk.map((x) => x.toString(16).padStart(2, "0")).join(" ");
      const asc = chunk.map((x) => (x >= 32 && x < 127) ? String.fromCharCode(x) : "·").join("");
      lines.push(i.toString(16).padStart(8, "0") + "  " + hex + "  " + asc);
    }
    const pre = document.createElement("pre");
    pre.style.cssText = "margin:12px;font:12px/1.7 Consolas,monospace;white-space:pre;overflow:auto";
    pre.textContent = lines.join("\n");
    ctx.host.appendChild(pre);
    ctx.setStatus({
      title: ctx.name,
      encoding: `字节 ${b.length}`,
      position: "显示前 4096 字节",
      mode: "模式: 十六进制",
      display: "外部插件",
    });
  },
};

export default plugin;
```

## 开发与打包

插件必须是**自包含单文件 ESM**（不能 `import` npm 包或宿主模块——宿主模块只打包进应用自身）。推荐用 esbuild 打包：

```bash
# 插件项目结构：
#   manifest.json
#   src/main.ts        （+ 自备的接口类型声明）
#   build.sh

npx esbuild src/main.ts --bundle --format=esm --outfile=main.js --target=es2022
cd package-root && zip -r ../my-plugin.rbplugin manifest.json main.js
```

类型声明：把 [`src/plugins/types.ts`](../src/plugins/types.ts) 复制一份进插件项目（仅作类型检查用，不参与打包）。

### 安装 / 更新 / 卸载

- **安装**：菜单「工具 → 插件管理 → 📦 安装插件…」，选择 `.rbplugin`（或 `.zip`）文件。解包到应用数据目录 `plugins/<id>/`。
- **更新**：直接再次安装同 `id` 的包，旧目录被替换。
- **卸载**：插件管理面板中外部插件行有「卸载」，目录移入系统回收站（可恢复）。
- 启停开关对内置与外部插件一致，状态持久化。

### 调试

- `npm run dev`（浏览器演示模式）内置一个走完整外部链路的演示插件「十六进制查看」，可打开演示书库中的 `示例数据.hex` 查看效果。
- 插件的 `console.log` 输出在 DevTools 控制台可见（桌面端右键 → 检查）。
- 加载失败的包会在插件管理面板显示红色错误行（含原因），修复后重新安装即可。

## 安全模型（当前版本）

- 插件代码运行在**宿主 WebView 主框架**中，与内置插件同环境——请**只安装可信来源的插件**。
- 能力收口：外部插件拿不到宿主的 `api`/`app` 模块，只能使用 `ctx` 上的方法；`loadBytes` 限定在当前打开文件所在目录/压缩包内（路径穿越拒绝）。
- Rust 侧不执行任何插件代码，只做包管理；安装时校验 manifest（id 格式、API 版本、扩展名格式、条目路径穿越）。
- 后续版本计划：签名校验、CSP 收紧、Worker 沙箱化执行。在落地前，插件分发应通过可信渠道并对包做哈希比对。
