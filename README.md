# ReadBook - 文本阅读器

复刻经典阅读软件 ReadBook（见 `../READBOOK.HLP`）便携功能的现代实现，基于 **Tauri 2 + Vite + 原生 TypeScript** 构建。

## 功能

| 功能 | 说明 | 快捷键 |
|------|------|--------|
| 打开 TXT / ZIP | 编码自动识别（BOM → UTF-8 → chardetng → GB18030 回退），ZIP 内多 TXT 弹出选择 | `Ctrl+O` |
| 按序号翻文件 | 智能序号排序（A1→A2→…→A9→A10） | `Ctrl+PgUp` / `Ctrl+PgDn` |
| 连续滚屏 | requestAnimationFrame 平滑滚动，鼠标纵向位置实时调速，滚屏时隐藏鼠标 | `Space` |
| 滚屏速度 | 1–9 档位快捷键；具体数值（像素/秒）点工具栏速度标签弹层查看/滑选/手工输入任意值 | `1-9`、`+` / `-` |
| 页模式翻页 | 定时整页翻动（间隔可在设置中调） | `P` 切换 |
| 手动翻页 | | `PgUp` / `PgDn` |
| 位置回退 | 跳转前位置入栈，可逐级返回 | `Ctrl+Z` |
| 配色方案 | 内置 12 种（白纸/护眼绿/羊皮纸/夜间黑/深蓝夜读等），可改色/字体/字号/行距并另存自定义方案 | 视图菜单 |
| 字号快捷档 | 小/较小/中/较大/大 五档 | 外观面板 |
| 简繁显示切换 | 原码 / 简体 / 繁体（内嵌 OpenCC 字符表，`npm run gen:simptrad` 重新生成） | 工具栏"简"按钮循环 |
| 重新排版 | 去硬回车重分段，不破坏段落（后端处理） | `F5` |
| 查找 | `?` 通配任意一个英文字母或汉字，全部高亮逐个跳转 | `Ctrl+F`、`F3` |
| 关键词检索与统计 | 关键词组管理；统计按命中频次排序；索引按行号+上下文列出，点击跳转（仅索引高亮+跳转闪示） | `Ctrl+K` |
| 文件夹浏览 | 左侧栏树状浏览（懒展开）+ 文件列表（含子目录/名称过滤），支持重命名/新建文件夹/删除（进回收站）/归档移动，删除当前文件自动接续下一个 | `Ctrl+Shift+O` |
| SMB 远程共享 | 左侧栏「远程」标签：连接 Samba/NAS 服务器（多服务器配置，支持匿名/账号），只读浏览并直接打开远程 TXT/ZIP（流式读取），可「缓存到本地」加速重复打开；断网时自动用旧缓存兜底；远程 zip 仅拉取中央目录与所需条目区间 | `Ctrl+Alt+O` |
| 文件夹定位 | 阅读区右键菜单，在文件夹栏中定位并高亮当前文件（远程文件定位到远程标签） | 右键 |
| 插件系统 | 内置与外部插件在「插件管理」中启停（持久化），启用插件的固定设置显示在菜单栏「插件」菜单（一级入口即「打开插件管理」）；外部插件为 `.rbplugin` 包（zip + manifest.json + 单文件 ESM 入口，Rust 负责安装/卸载，前端动态加载，开发接口见 [docs/插件开发.md](docs/插件开发.md)）；插件视图激活时窗口标题/右上角显示打开的文件，状态栏"文件"格与各格由插件上报；内置插件：图片查看（滚轮以鼠标为焦点缩放/旋转，缩放模式下拉：适应窗口·适宽·适高·原始大小，幻灯播放，自动滚屏向下·向右·向左，无缝拼接预加载，跨目录与跨压缩包接续）、视频查看（播放/暂停·进度条跳转·倍速·音量/静音·全屏，同目录/同压缩包内上一个/下一个与自动连播，`<video playsinline>` 触屏就绪，2GB+ 大文件经宿主流式协议按 Range 分块播放——本地文件与本地 zip 存储型条目，压缩条目/SMB 自动回退整读） | 工具菜单 / 插件菜单 |
| 书签 | 带描述，跨书保存，点击跳转 | `Ctrl+B` |
| 收藏书架 | 收藏常用书籍快速打开；插件中查看的文件（如图片）同样可收藏 | `Ctrl+Shift+S` |
| 历史记录 | 记录阅读时长与位置，打开时自动恢复到上次位置 | 工具栏 |
| 启动自动恢复 | 自动装入上次阅读的文件并定位（视图菜单可关） | 启动时 |
| 双页模式 | 高分屏左右双页横向翻阅 | `Ctrl+D` |
| 全屏阅读 | 隐藏菜单/工具栏/状态栏 | `F11` |
| 局部编辑 | 选中文字（或双击选词）→ 弹窗修改 → 写回原文件（保留原编码） | `Ctrl+E` |
| 另存为新文件 | 可选 UTF-8 / GB18030 / Big5 / UTF-16LE / UTF-16BE 编码 | `Ctrl+S` |
| 系统托盘 | 关闭窗口隐藏到托盘，托盘菜单恢复/退出；快速隐藏 | `T`、`Ctrl+Q` 退出 |

所有设置、书签、收藏、历史持久化在系统应用数据目录的 `readbook.json`（SMB 服务器配置含账号密码，同样明文保存在此文件中——单机使用约定，keyring 属未来增强）。SMB 本地缓存在系统应用缓存目录的 `smb/` 子目录，可用面板菜单一键清空。

### SMB 支持说明

- 协议实现为纯 Rust 的 [`smb2`](https://crates.io/crates/smb2) crate（无 FFI），Windows/macOS/Linux/iOS 均可编译；**仅支持 SMB2/3，不支持 SMB1**（2012 年后的设备默认即 SMB2+，一般无影响；极老设备请先在固件中开启 SMB2）。
- 远程路径以规范形式 `smb://<服务器id>/<共享名>/<路径>` 流入历史/书架/自动恢复，与本地路径（含 `zip::条目` 复合路径）共用同一套打开管线；删除服务器配置后旧路径条目会提示失效。
- 远程侧只读：浏览与打开之外不提供删除/重命名/移动等操作。

## 开发

```bash
npm install
npm run tauri dev     # 桌面应用（需要 Rust 工具链）
npm run dev           # 仅前端：浏览器预览（内置演示书与 mock 后端）
npm run gen:simptrad  # 重新生成简繁字符表（需 devDependency: zhconv）
```

## 构建

```bash
npm run tauri build
```

```
readbook/

├── src/                     # 前端（Vite + 原生 TS）
│   ├── main.ts              # 入口（无 Tauri 环境时加载演示后端）
│   ├── app.ts               # 主状态与全部动作
│   ├── reader.ts            # 阅读渲染、滚屏引擎、页模式、双页
│   ├── menubar.ts           # 菜单定义与工具栏绑定
│   ├── panels.ts            # 书签/书架/历史/外观面板
│   ├── findbar.ts           # 查找（? 通配符高亮）
│   ├── shortcut.ts          # 全局快捷键
│   ├── dropdown.ts          # 通用下拉菜单
│   ├── themes.ts            # 内置配色方案
│   ├── simp_trad.ts         # 简繁转换（数据见 simp_trad_data.ts）
│   ├── smb.ts               # SMB 远程面板（服务器树/文件列表/缓存管理）
│   ├── mock_backend.ts      # 浏览器演示后端（生产不加载）
│   ├── plugins/
│   │   ├── types.ts         # 插件接口（ReadBookPlugin / PluginOpenContext）
│   │   ├── registry.ts      # 注册表与中央打开管线（启停/状态上报/管理面板）
│   │   ├── loader.ts        # 外部插件加载器（.rbplugin → blob import）
│   │   └── image-viewer.ts  # 内置插件：图片查看
│   └── styles.css
└── src-tauri/               # 后端（Rust）
    └── src/

        ├── encoding.rs      # 编码识别与回写（encoding_rs + chardetng）

        ├── plugin_pkg.rs    # 外部插件包安装/卸载/列举（.rbplugin）
        ├── reorder.rs       # 重新排版
        ├── seqfile.rs       # 按序号找上/下一个文件
        ├── store.rs         # 设置/书签/历史/收藏持久化
        └── lib.rs           # 命令注册、系统托盘、关闭到托盘
```
